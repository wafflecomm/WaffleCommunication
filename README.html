1 핵심 기능 (Key Features)

4개 국어(KO/EN/JA/ZH) i18n 엔진

0ms 인메모리 자체 내장 엔진으로 브라우저 언어 자동 감지, LocalStorage 영구 보존, URL 파라미터(?lang=) 실시간 전환을 완벽 지원합니다.

Antigravity Hero & Vantablack Luxe

순수 바닐라 JS 물리 엔진으로 구현된 마우스 반응형 무중력 파티클 애니메이션과 하이엔드 글래스모피즘 UI를 선사합니다.

국내 PortOne V2(카드/카카오/토스) 및 해외 PayPal 듀얼 결제, Supabase PostgreSQL 실시간 피드, 축하 영수증 모달을 지원합니다.

전자상거래 준수 & 글로벌 SEO

통신판매업 신고(제2026-서울강남-04919호), 3대 약관(이용약관/개인정보/환불) 및 4개 국어 hreflang 다국어 sitemap.xml을 완비했습니다.
