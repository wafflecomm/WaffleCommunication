환경별 의미

localhost:5173

Gemini UI/UX 작업의 미리보기입니다. 운영 서버가 아닙니다.

localhost:5181 등

Codex 로직 작업의 미리보기입니다. 안내된 포트는 작업마다 달라질 수 있습니다.

GitHub main

승인된 UI와 로직을 모두 포함하며 웹 배포와 앱 빌드의 기준입니다.

권장 배포 절차

  1. Gemini와 Codex가 각자 전용 브랜치에서 작업하고 로컬 미리보기를 제공합니다. Gemini는 npm run dev, npm run build, npm run preview까지만 실행합니다.
  2. 사용자가 UI와 기능을 확인하고 반영을 승인합니다.
  3. 각 담당자가 자신의 변경만 커밋하고 브랜치에 푸시합니다.
  4. Codex가 최신 main과 Gemini 변경을 확인한 뒤 승인된 변경만 통합합니다.
  5. 충돌·누락과 프로덕션 빌드를 확인하고 사용자 승인 후 main에 푸시합니다.
  6. 깨끗한 main에서 HEAD와 origin/main이 같은지 확인한 뒤 npm run deploy를 실행합니다.
  7. Cloudflare Production 환경, 운영 URL HTTP 200, 최신 자산과 배포 SHA가 최종 main과 같은지 확인합니다.
  8. Claude에게 확정 SHA를 전달하고 동일한 소스로 앱을 빌드합니다.
  9. 앱 버전과 업데이트 정책을 맞춘 뒤 스토어에 제출합니다.

배포 권한과 자동 차단 조건

Gemini가 실행하지 않는 작업

  • npm run deploy, wrangler pages deploy 등 배포 명령
  • Cloudflare 대시보드/API 배포와 운영 환경 변수 변경
  • Cloudflare API 토큰 생성·조회·복사·사용
  • main 병합·푸시와 배포 보호 절차 우회

운영 배포 통과 조건

  • 현재 브랜치가 main일 것
  • 작업 트리에 미커밋 변경이 없을 것
  • 현재 HEAD가 origin/main과 정확히 일치할 것
  • 작업 브랜치 Preview가 아닌 Cloudflare Production으로 등록될 것

배포 스크립트가 조건 불일치로 중단되면 우회하지 않습니다. Gemini는 브랜치와 테스트 결과를 Codex에 전달하고, Codex가 통합·검증·승인 절차를 마친 뒤 운영에 반영합니다.
