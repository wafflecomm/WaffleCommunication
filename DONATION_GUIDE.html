☕ Engineering Spec

미니멀 커피 후원 플랫폼 개발 지침서

개발자, 크리에이터, 오픈소스 메인테이너를 위한 모바일 퍼스트 미니멀 후원 플랫폼 구축 및 PortOne V2 / PayPal 연동 공식 가이드라인입니다.

1. 📌 개요 및 기획 목표

외부 링크(블로그, GitHub README, SNS 프로필 등)를 통해 사용자가 손쉽게 유입되어 커피(후원금)를 전달할 수 있는 가볍고 직관적인 단일 페이지 웹 애플리케이션입니다.

🚀

무설치 & 초경량 아키텍처

회원가입이나 앱 설치 없이 URL 클릭 한 번으로 후원이 완료되는 Zero-Friction UX를 지향합니다.

💳

국내/해외 통합 결제

PortOne V2(카드/카카오/토스)와 PayPal JS SDK를 통해 국내외 결제를 모두 지원합니다.

🔗

다이렉트 딥링크 파라미터

URL 파라미터(?target=insub&amount=9000)를 통해 크리에이터와 후원 금액을 사전 지정합니다.

🌗

시스템 다크모드 자동 연동

OS의 prefers-color-scheme 설정을 감지하여 실시간으로 부드러운 다크/라이트 테마를 제공합니다.

🔗 1. 링크 유입 URL 파라미터 파싱
☕ 2. 잔 수 선택 1/3/5잔 or 직접입력
✍️ 3. 정보 입력 닉네임 & 응원 메시지
💳 4. 결제 진행 PortOne / PayPal
🎉 5. 완료 & 피드 영수증 & 실시간 반영

5. ⚙️ 핵심 기술 구현 상세 코드

5.1. 시스템 다크모드 자동 감지 (OS Sync)

// OS 다크모드 설정 감지 및 실시간 이벤트 리스너
function initTheme() {
  const darkModeMediaQuery = window.matchMedia('(prefers-color-scheme: dark)');
  
  function applyTheme(isDark) {
    if (isDark) {
      document.documentElement.classList.add('dark');
    } else {
      document.documentElement.classList.remove('dark');
    }
  }

  // 최초 로드 시 OS 설정값 반영
  applyTheme(darkModeMediaQuery.matches);

  // OS 설정 변경 시 실시간 반영
  darkModeMediaQuery.addEventListener('change', (e) => applyTheme(e.matches));
}

5.2. 다이렉트 딥링크 파라미터 파싱

// URL 쿼리 파라미터 파싱 및 크리에이터 프로필 자동 설정
function parseUrlParams() {
  const params = new URLSearchParams(window.location.search);
  const target = params.get('target') || '와플커뮤니케이션';
  const amount = parseInt(params.get('amount'), 10) || 3000;
  const message = params.get('message') || '';

  return { target, amount, message };
}

5.3. PortOne V2 결제 연동 (인앱 브라우저 호환)

async function requestPortOnePayment({ target, amount, nickname, message }) {
  const paymentId = `pay_${Date.now()}_${Math.random().toString(36).substring(2, 7)}`;
  
  const response = await PortOne.requestPayment({
    storeId: "YOUR_STORE_ID",
    paymentId: paymentId,
    orderName: `☕ ${target} 님을 위한 커피 후원`,
    totalAmount: amount,
    currency: "CURRENCY_KRW",
    payMethod: "CARD",
    customer: { fullName: nickname || "익명의 후원자" },
    customData: { target, message },
    // 카카오톡/인스타 인앱 브라우저 대응을 위한 필수 리디렉션 URL
    redirectUrl: `${window.location.origin}${window.location.pathname}?paymentId=${paymentId}`
  });
}

6. 🛡️ 보안 및 운영 고려사항

1. 결제 위변조 방지 (Server Validation)

클라이언트(브라우저)에서 금액 조작을 방지하기 위해, 결제 완료 후 PortOne/PayPal API를 호출하여 실제 승인된 금액과 paymentId를 백엔드/Serverless에서 재검증해야 합니다.

2. 모바일 인앱 브라우저 팝업 차단 방지

카카오톡, 인스타그램 인앱 브라우저는 팝업 창을 강제 차단할 수 있으므로, 반드시 redirectUrl 파라미터를 설정하여 페이지 전환 방식으로 결제가 진행되도록 해야 합니다.

3. 크리에이터 타겟 식별자(target) 전송

다이렉트 링크를 통해 여러 사람이 하나의 도메인을 공유하므로, 결제 메타데이터(customData)에 target 식별자를 포함해 정산 및 후원자 명단을 분리해야 합니다.
